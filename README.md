# Fides in anima

Aplicativo estático instalável (PWA), sem dependências. Publique esta pasta na raiz de um repositório GitHub Pages com HTTPS. Todos os caminhos são relativos e funcionam em um endereço de projeto.

## Uso

1. Abra o endereço publicado no celular.
2. Toque em Instalar no celular. No iPhone, use Safari → Compartilhar → Adicionar à Tela de Início.
3. Transfira o arquivo `minha-biblioteca.json` para o aparelho e use Importar biblioteca.

A biblioteca fica no IndexedDB do aparelho e não é enviada ao servidor. Não publique o arquivo da biblioteca ou os PDFs no repositório. Limpar os dados do navegador remove a biblioteca; guarde o arquivo para importar novamente. No iPhone, importe depois de abrir o aplicativo instalado.

A leitura é selecionada pela data local e muda às 6h. O aplicativo atualiza ao abrir, ao voltar à tela ou a cada minuto enquanto aberto. Não envia notificações com o aplicativo fechado. O link diário dos Salmos abre o jw.org e precisa de internet. As leituras importadas ficam disponíveis offline depois do primeiro carregamento do aplicativo.

O arquivo fornecido como Fides in animas de Sabedoria é material de divulgação, não o livro completo. A biblioteca contém textos extraídos de Sinal Verde e Vinha de Luz e um trecho de Pai Nosso; a extração dos PDFs pode conservar imperfeições de OCR.
