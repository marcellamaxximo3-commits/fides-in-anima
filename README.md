# Fides in anima

PWA de leitura diária. Uma mensagem dos livros é escolhida pela data local e muda às 2h, ao abrir o aplicativo. As leituras estão incluídas e ficam disponíveis offline após o primeiro acesso. Não exige importação. Salmos disponíveis como leitura adicional no jw.org.

A data usa o horário local do aparelho. A leitura é recalculada ao abrir, voltar à tela, recuperar o foco e às 2h com o aplicativo aberto. Aquarelas alternam diariamente e recebem uma composição associada à leitura.
